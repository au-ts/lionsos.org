# 'Hello World' Tutorial

This is the primary introductory tutorial for LionsOS. Its goal is to familiarise
you with setting up a system based on LionsOS, and to demonstrate basic usage of
our build system and using our OS services, specifically, Ethernet/IP.

We demonstrate building a [Memcached](https://memcached.org/) compatible service
on top of LionsOS.
